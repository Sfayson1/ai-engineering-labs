## 2. Key Concepts

### Large Language Model (LLM)

A large language model processes and generates text by predicting tokens based on learned patterns and probabilities.

### SDK vs. API vs. Model

- **SDK:** A collection of development tools and libraries that simplifies communication with a service.
- **API:** An interface that allows applications to communicate with another system.
- **Model:** The underlying AI system responsible for generating responses.

The OpenAI SDK allows my Python application to communicate with the OpenAI API, which provides access to models such as GPT-4.1.

### Inference

Inference is the process of using an already-trained model to generate an output. My chatbot performs inference rather than training a model.

### Temperature

Temperature controls the variability of model-generated responses.

Setting temperature to 0 favors the most probable tokens, making responses more predictable. However, this does not guarantee factual accuracy or identical responses.

### Tokens

Tokens are units of text processed by a language model.

- Input tokens: Tokens processed as input.
- Output tokens: Tokens generated by the model.
- Total tokens: Input tokens plus output tokens.

Monitoring token consumption is important for managing API costs and application limitations.

## 3. Python Development Environment

### uv

uv is a Python package and project manager that handles dependencies, virtual environments, and project execution.

| Command   | Purpose                                   |
| --------- | ----------------------------------------- |
| `uv init` | Initialize a Python project               |
| `uv add`  | Install and declare a dependency          |
| `uv run`  | Execute code within a project environment |
| `uv sync` | Synchronize project dependencies          |

### Project Files

| File or Directory | Purpose                                           |
| ----------------- | ------------------------------------------------- |
| `.venv/`          | Isolated Python environment and dependencies      |
| `.env`            | Environment variables and sensitive configuration |
| `pyproject.toml`  | Project metadata and dependency declarations      |
| `uv.lock`         | Resolved dependency versions                      |
| `.gitignore`      | Prevents unwanted files from being tracked        |

### Credential Management

API keys and database connection strings should be stored separately from application code.

The `load_dotenv()` function loads configuration from a `.env` file into the process environment.

A `.env` file is not encrypted and must be properly protected and excluded from version control.

## 4. Textbook Implementation

**File:** `hello_world/chatbot.py`

Built a basic Python application that sends a predefined question to GPT-4.1 using the OpenAI Responses API.

### Application Workflow

1. Import required dependencies.
2. Load environment variables.
3. Initialize the OpenAI client.
4. Send a request to the model.
5. Receive the response.
6. Display the generated text.

### API Parameters

| Parameter     | Purpose                               |
| ------------- | ------------------------------------- |
| `model`       | Specifies the model to use            |
| `temperature` | Controls output variability           |
| `input`       | Contains the prompt sent to the model |

### Response Properties

- `response.output_text`: Generated text.
- `response.usage.input_tokens`: Input token consumption.
- `response.usage.output_tokens`: Output token consumption.
- `response.usage.total_tokens`: Total token consumption.

## 6. Debugging and Troubleshooting

### Error 01: uv Command Not Found

**Cause:** uv was not available in the terminal.

**Resolution:** Installed uv.

**Lesson:** Development tools must be installed and accessible before they can be executed.

### Error 02: Pylance Missing Import

**Likely cause:** VS Code was not using the project's virtual environment.

**Resolution:** Use the Python interpreter associated with the uv project.

**Lesson:** Installing dependencies and configuring an IDE are separate responsibilities.

### Error 03: ModuleNotFoundError

**Cause:** The independent experiment was executed outside the uv project containing its dependencies.

**Resolution:** Executed the experiment using the hello_world project environment.

`uv run python ../experiments/interactive_chatbot.py`

**Lesson:** Dependencies installed in one virtual environment are not automatically available in another.

### Error 04: Missing API Credentials

**Cause:** The `.env` file was located in hello_world, a sibling directory of experiments.

**Resolution:** Moved the `.env` file to the shared chapter-01 directory.

**Lesson:** Dependency management and configuration management are separate concerns. Correctly installed dependencies do not guarantee that an application is properly configured.

## 7. Engineering Decisions

### Why use uv?

To simplify dependency management and create reproducible Python development environments.

### Why use environment variables?

To separate sensitive configuration from application source code.

### Why use temperature 0?

To favor more predictable model-generated responses, while recognizing that predictability does not guarantee accuracy.

### Why monitor tokens?

To understand resource consumption and manage the operational costs of AI applications.

## 8. Technical Interview Questions

**What is the difference between .venv and .env?**

A .venv is an isolated Python environment containing installed dependencies. A .env file stores environment-specific configuration separately from application code.

**What does total token consumption represent?**

The combined number of input and output tokens used during an API request.

**What is the purpose of temperature?**

Temperature influences the variability of generated responses.

**Does temperature 0 guarantee factual accuracy?**

No. A model can generate a predictable but incorrect response.

**Where is the AI model running?**

The model runs on remote infrastructure. My Python application communicates with it through an API.
